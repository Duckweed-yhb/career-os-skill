# 第 01 课：环境搭建与第一行 JavaScript（零基础）

> 示例课程：面向**完全零基础**用户的第一课。注意对比有基础版 01 课——零基础版不急着做 API，先把"代码是什么"讲透。

## 学习目标

- 装好 Node.js，理解"运行环境"这个概念
- 写出并运行你的第一行 JavaScript 代码
- 理解变量：在代码里存一个值，再把它打印出来

## 前置要求

- 无。这是你的第一课，唯一需要的是能打开电脑上的终端

## 最小知识

**编程在做什么**：你在写"指令"，电脑按顺序执行。就这么简单。

**JavaScript 是什么**：一种编程语言，原本在浏览器里跑，现在也能在电脑上直接跑（靠 Node.js 这个"运行环境"）。

**第一行代码长这样**：

```js
console.log("你好，世界")
```

`console.log(...)` 是"把括号里的东西打印到屏幕"的指令。

**变量**：给一个值起个名字，后面可以反复用：

```js
let 我的名字 = "小明"
console.log(我的名字)
```

## 动手任务

1. 打开 [nodejs.org](https://nodejs.org)，下载 **LTS 版**并安装（一路默认下一步）。
2. 打开终端（Windows 搜 "PowerShell"），输入 `node -v`，回车——看到 `v20` 或更高就成功了。
3. 新建文件夹 `taskflow`，在里面新建文件 `hello.js`，写下：

   ```js
   let name = "小明"
   let year = 2026
   console.log("你好，" + name + "，现在是" + year + "年")
   ```

4. 在终端里进入该文件夹：`cd taskflow`，然后运行：

   ```bash
   node hello.js
   ```

5. 看到 `你好，小明，现在是2026年` 就完成了。试试把 `year` 改成别的数再运行一次。

## 验收标准

- [ ] `node -v` 输出 v20 或更高版本号
- [ ] `node hello.js` 能打印出那行问候语
- [ ] 修改 `year` 的值后，运行结果跟着变

## 常见坑

- **装完 node 命令找不到**：重启一下终端（PATH 没刷新）
- **`console.log` 里加号拼中文没问题，但忘加引号会报错**：字符串必须用引号包起来
- **文件名或路径有中文**：先在纯英文路径下练习，后面课程会用到命令行，中文路径容易出幺蛾子

## 预计时长

- 约 1–2 小时（含安装）
