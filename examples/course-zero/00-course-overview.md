# TaskFlow 课程总览（零基础版 · 00）

> 示例：同一项目 TaskFlow，**零基础**用户的课程方案。与 `examples/course/`（有基础版）对比，可以看到 CareerOS 如何按基础水平自适应。
> 用户画像：**完全没写过代码**，每周可投入 10 小时。

---

## 一、技术栈学习路线（零基础）

| 顺序 | 学习单元 | 依赖 | 说明 |
|---|---|---|---|
| 1 | JavaScript 语法基础 | — | 零基础必修，拆成 4 节课 |
| 2 | 命令行与工具链 | — | 终端、npm、Git 各 1 节 |
| 3 | Node.js 与 HTTP 基础 | JS | 从内置 http 模块起步，不直接上框架 |
| 4 | Fastify 框架 | Node/HTTP | 有前面铺垫后引入 |
| 5 | PostgreSQL 数据建模 | — | 用 Docker 装库，概念先行 |
| 6 | 认证：JWT + 密码哈希 | 中间件 | 拆成 2 节课 |
| 7 | Redis 缓存 | Node 基础 | M4 阶段 |
| 8 | Docker 与部署 | Git/Node | 最后一环 |

**对比有基础版**：多了 5 节入门课（JS 语法 ×4、工具链 ×1），框架课延后——零基础先懂"HTTP 是什么"再学框架。

## 二、项目开发路线（4 个里程碑）

- **M1 环境与基础（课 01–06）**：能运行 JS 脚本、会用 Git 管理代码
- **M2 后端与数据（课 07–13）**：一个有认证的 API 服务 + 四张数据库表
- **M3 核心功能（课 14–17）**：任务 CRUD + 状态流转 + 测试
- **M4 加固与上线（课 18–20）**：Redis 缓存 + Docker + 作品集收尾

## 三、课程表与学习排期

每周 10 小时，每课约 2–3 小时（零基础含练习时间），排期 10 周：

| 周次 | 课程 | 里程碑 |
|---|---|---|
| 第 1 周 | 01 JS 语法 · 02 类型与函数 · 03 数组与对象 | M1 |
| 第 2 周 | 04 命令行与 npm · 05 Git 入门 · 06 第一个脚本 | M1 |
| 第 3 周 | 07 HTTP 与第一个服务 · 08 Fastify 框架 | M2 |
| 第 4 周 | 09 数据库概念 · 10 表设计与迁移 | M2 |
| 第 5 周 | 11 注册接口 · 12 密码哈希与登录 | M2 |
| 第 6 周 | 13 中间件与鉴权 · 14 任务 CRUD（上） | M2/M3 |
| 第 7 周 | 15 任务 CRUD（下） · 16 状态流转 | M3 |
| 第 8 周 | 17 测试入门 · 18 Redis 缓存 | M3/M4 |
| 第 9 周 | 19 Docker 化与一键启动 | M4 |
| 第 10 周 | 20 收尾：README、复盘、能力复核 | 全部 |

**总计 20 课 · 10 周**。对比有基础版（13 课）：课时更小、节奏更慢、每课知识量更少。

## 四、零基础怎么学

1. 每课只学一个主题，**最小知识控制在 10 分钟内**，剩下时间全部动手。
2. 卡住先自己看报错，再向 CareerOS 要"最小提示"——它会一步步带你，而不是直接给答案。
3. 每周结束检查排期表：落后了就减量（把 3 课压成 2 课），不要跳课。
4. 完成 M1 里程碑时做一次复盘，把技能矩阵更新进 `career-profile.md`。

打开 `01-js-and-tooling-basics.md`——装好 Node.js，写出你人生第一行代码。
